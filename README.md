## 🇪🇸 Español

Ejercicios y tareas del curso de **Java Avanzado**, organizados por tarea. Cubren patrones de diseño, manejo de excepciones, colecciones en memoria y programación orientada a objetos.

### 📁 Contenido

| Tarea | Tema |
|---|---|
| `Tarea1` | Patrón Singleton |
| `Tarea2` | Manipulación de strings (`FunctionString`) |
| `Tarea3` | Manejo de excepciones personalizadas (`ExceptionLauncher`) |
| `Tarea4` | CRUD de usuarios en memoria (versiones `Inicial` y `Final`), parseo de opciones (`OptionParser`) |
| `Tarea5` | Herencia y polimorfismo: `Motor`, `CocheElectrico`, `CocheGas` |

### 🔧 Tecnologías

- Java
- IntelliJ IDEA (`.iml`)

## 🇬🇧 English

Exercises and assignments from the **Advanced Java** course, organized by task. They cover design patterns, exception handling, in-memory collections, and object-oriented programming.

### 📁 Contents

| Task | Topic |
|---|---|
| `Tarea1` | Singleton pattern |
| `Tarea2` | String manipulation (`FunctionString`) |
| `Tarea3` | Custom exception handling (`ExceptionLauncher`) |
| `Tarea4` | In-memory user CRUD (`Inicial` and `Final` versions), option parsing (`OptionParser`) |
| `Tarea5` | Inheritance and polymorphism: `Motor`, `CocheElectrico`, `CocheGas` |

### 🔧 Technologies

- Java
- IntelliJ IDEA (`.iml`)
